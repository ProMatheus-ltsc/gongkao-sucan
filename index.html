课堂批注 + 一起导出 PDF

讲到哪、写到哪。线上版也能导出：批注和幻灯片叠在同一页，不用再合成。

  1. 开画笔
    演示时点左下角工具条上的铅笔图标，即可在任意一页手写、画线。数字 1–7 换颜色，S 笔 / L 直线 / R 矩形 / E 椭圆，Esc 退出。
  2. 自动存档
    批注自动保存在当前浏览器里（线上版也一样），刷新或关掉页面都不会丢，下一节课接着写。
  3. 导出带批注的 PDF
    点幻灯片右下角的 「导出 PDF」，在导出页点 PDF，浏览器打印时选「另存为 PDF」即可。GitHub Pages 线上版同样可用。
# 也可以在本机课件目录直接导出（含批注）
cd 除法估算-slidev
npm install         # 首次
npm run export:pdf  # 含批注

在线导出：乘法课件 · 除法课件。网址用 #/ 路由，刷新不会 404。线上批注只留在你自己的浏览器，学生在自己设备上打开看到的是干净课件；把批注版导出成 PDF 发给学生即可。
